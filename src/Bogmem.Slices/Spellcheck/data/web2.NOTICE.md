# web2 English word corpus

BogMem embeds `web2.txt.gz`, a compressed copy of the `web2` American-English
word list maintained and distributed by The FreeBSD Project.

The corpus is derived from *Webster's Second International Dictionary*. The
FreeBSD source notes that the dictionary's 1934 copyright has lapsed. BogMem
acknowledges Webster's Second International Dictionary as the original source
and The FreeBSD Project for maintaining and distributing the word list.

Upstream source:

<https://github.com/freebsd/freebsd-src/blob/df38c129b0ce967f6b8cca8d863f23915b315def/share/dict/web2>

The upstream file was compressed without content changes using `gzip -n -9`.
